# Nightfall

A lunar and celestial look for the Claude desktop and mobile apps.

- A midnight navy and gold palette in dark mode, and a moonstone gray-blue palette in light mode.
- A backdrop of about 2,270 real stars with the figures of about 30 constellations, drawn as the
  sky looks when you face north. It turns at the real rate and is oriented by the current
  sidereal time, with longitude estimated from the computer's time zone.
- A moon drawn at its real phase for the current date.
- A context gauge above the message box: ten stars, one lit for each 10% of the context window
  in use, with the percentage beside them.
- A `/lunar` command that turns the look off or on for the current session.

The terminal draws no backdrop or colors. There the mod shows only the gauge row.

## Install

At the prompt of a terminal session:

```
/plugin install nightfall --marketplace kevinaroe/nightfall
```

From a shell:

```
claude plugin install nightfall --marketplace kevinaroe/nightfall
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins,
Add marketplace with `kevinaroe/nightfall`, then Add plugin.

## Use

The look applies when a session starts. Type `/lunar off` to turn it off for that session and
`/lunar on` to bring it back. `/lunar` alone switches between the two.

## Files

- `hooks/register.tsx`: the palette, message styles, the gauge row and the `/lunar` command.
- `hooks/scene.js`: the backdrop drawing (sky and moon).
- `hooks/sky.js`: the star data and constellation figures, generated by `build-sky.mjs`.
- `build-sky.mjs`: rebuilds `sky.js` from a star catalog file.
- `tests/gauge.test.tsx`: a test that the gauge row draws. Run it with `claude plugin test .`.

## Star data

Star positions, magnitudes and colors come from the `stars.6.json` catalog of the d3-celestial
project (Copyright (c) 2015, Olaf Frohn, BSD 3-Clause license), which is drawn from the Hipparcos
and Yale Bright Star catalogs. Its license text is in `THIRD_PARTY_NOTICES.md`. The constellation
figures are written by hand.
